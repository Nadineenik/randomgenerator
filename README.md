# Генератор Очереди 🎲

Простое и удобное Android-приложение для генерации случайной очереди с **особыми условиями**.

Идеально подходит для:
- Очередей в группе (школа, вуз, кружок, волонтёрство)
- Распределения номеров
- Игр и соревнований

## Основные возможности

### Генератор
- Задаёшь диапазон (от 1 до 24, например)
- Указываешь, сколько чисел нужно сгенерировать
- Переключатели: «Без повторов» и «Сортировать по порядку»
- **Особые условия** — можно зафиксировать определённые номера в нужном диапазоне позиций

### Особые условия (хитринка)
Хочешь, чтобы конкретный человек (например, №13) шёл в начале очереди (позиции 1–5)?  
Добавь правило:  
**Число 13 → позиции 1–5**

При генерации приложение автоматически разместит это число в заданном диапазоне, а остальные числа перетасует случайно.

### После генерации
- Красивые карточки с номерами
- Над каждым номером — **порядковый номер в очереди** (1, 2, 3…)
- Кнопка **«Копировать очередь»** — одним нажатием копирует готовый список в буфер обмена
- Вибрация при генерации

## Установка

Скачай APK из раздела Releases или собери проект самостоятельно.

## Как использовать

1. Перейди на вкладку **Генератор**
2. Укажи диапазон (например, от 1 до 24) и количество чисел
3. При необходимости включи особые условия на вкладке **Настройки**
4. Нажми «Сгенерировать»
5. Нажми «Копировать очередь» и отправь результат в чат группы

## Настройки

- Включи «Особые условия»
- Добавляй правила: какое число должно быть в каком диапазоне позиций
- Удаляй ненужные правила кнопкой корзины

## Технические детали

- Разработано на **Jetpack Compose**
- Данные сохраняются локально (JSON)
- Поддержка вибрации
- Копирование в буфер обмена
